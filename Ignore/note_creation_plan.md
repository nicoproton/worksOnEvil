# Obsidian Note Creation Plan for Thematic Research

This document outlines the working method for creating and revising Obsidian notes from `thematic_map_prompt.md`. The prompt remains private scaffolding in `Ignore/`; public notes should not link to it or treat it as the center of the graph.

## General Note Logic

Instead of a rigid template, each note should have a structure tailored to its subject matter.

* **Standalone prose:** Each note should first explain the work, author, or concept on its own terms.
* **Subject-specific architecture:** Headings should be designed around the logic of that subject, not reused from note to note.
* **Theme hubs over redundant work links:** When two works share a motif, create or use a concept note for that motif instead of linking the works directly.
* **Direct work-to-work links only when concrete:** Use direct links for influence, adaptation, explicit allusion, shared author/context, or a comparison explained in the same paragraph.
* **No generic See Also sections:** Links should appear where the prose explains the connection.
* **Exploratory tone:** The notes should preserve uncertainty and difference between works rather than forcing every subject into one thesis.
* **Metadata:** Use frontmatter aliases and tags for alternate titles, genres, and major themes.
* **Author notes must be theory-bearing:** Do not add author notes as biographies. Add or keep an author note only when it explains a concept, theory, recurring artistic problem, or interpretive framework that helps connect multiple works or concepts in the graph.

## Investigation & Creation Strategy

For each note:

1. **Contextualize:** Identify the work or concept's historical setting, genre, and primary concerns.
2. **Separate fact from interpretation:** Treat publication history, direct influence, and adaptation history differently from thematic resemblance.
3. **Draft a unique structure:** Choose headings that fit the subject's internal logic.
4. **Link intentionally:** Link concepts and works only when the sentence gives the reader a reason for the link.
5. **Add concept hubs as needed:** If a motif recurs across several notes, create a short concept note and let the works point there.

### Context Notes

Short context notes may exist for authors, source texts, or historical groups when public notes link to them directly. These should stay compact unless they become major research subjects.

Author notes should not be simple biographical entries. They should answer: what conceptual contribution does this author make to the graph? If the answer is only "they wrote this work," prefer linking directly to the work instead of creating an author note.
