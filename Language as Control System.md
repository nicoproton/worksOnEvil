# Language as Control System

Language as Control System names works where speech, code, naming, ritual, or symbolic structure directly governs thought and behavior. The motif appears when language stops being merely expressive and becomes executable.

This concept overlaps with [[Tower of Babel Archetype]] when control or collapse is tied to shared language, and with [[Weaponized Rationalism]] when language is formalized into a technical tool of command.

Use this link when words, code, or symbols function as an operating system for persons or societies.

In non-fiction media theory, the concept overlaps with [[Mediated Reality]] and [[Engineered Consent]], where public language helps construct the environment in which people form opinions.

William S. Burroughs gives the motif its viral media form. *[[Naked Lunch]]* begins the pattern through addiction, routines, voices, and grotesque control scenes, while *[[The Ticket That Exploded]]* and *[[Nova Express]]* make words, recordings, images, and scripts into explicit control systems that infect desire and behavior.
